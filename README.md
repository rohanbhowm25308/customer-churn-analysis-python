##  About The Project

**Customer Churn Analysis Using Python** is an end-to-end exploratory data analysis project built to understand customer behavior and identify patterns associated with customer churn.

The project follows a practical Data Science workflow:

```text
Raw Dataset
     ↓
Data Acquisition
     ↓
Data Understanding
     ↓
Data Cleaning
     ↓
Preprocessing
     ↓
Exploratory Data Analysis
     ↓
Visualization
     ↓
Interactive Analytics
     ↓
Automated Insights
     ↓
Data Story
```

Rather than jumping directly into Machine Learning, this project focuses on an important first stage of Data Science — **understanding and preparing the data correctly before modeling**.

---

## 🎯 Project Objectives

* Acquire and understand a real-world customer dataset
* Inspect dataset structure and data types
* Identify missing values and duplicate records
* Clean and preprocess the dataset
* Analyze customer churn patterns
* Explore relationships between customer characteristics
* Study contract, tenure and billing behavior
* Perform correlation analysis
* Create meaningful visualizations
* Build interactive Plotly visualizations
* Generate automated analytical insights
* Present findings through a structured data story

---

##  Dataset

The project uses the **IBM Telco Customer Churn Dataset**.

The dataset contains information related to:

* Customer demographics
* Subscription services
* Contract information
* Payment methods
* Monthly charges
* Total charges
* Customer tenure
* Churn status

### Dataset Features

| Category                | Examples                           |
| ----------------------- | ---------------------------------- |
|  Customer Information | Gender, Senior Citizen, Dependents |
|  Services             | Phone Service, Internet Service    |
|  Additional Services  | Online Security, Tech Support      |
|  Billing              | Monthly Charges, Total Charges     |
|  Contract             | Month-to-month, One year, Two year |
|  Tenure                | Customer tenure in months          |
|  Churn                | Yes / No                           |

## ✨ Key Features

###  1. Executive KPI Dashboard

The notebook dynamically calculates and displays:

* Total customers
* Number of churned customers
* Churn rate
* Retention rate
* Average tenure
* Average monthly charges

---

###  2. Data Quality Analysis

A dedicated data-quality workflow checks:

* Missing values
* Duplicate records
* Data types
* Invalid numerical values
* Dataset completeness

The project also includes a custom **Data Quality Score** to provide a quick overview of dataset quality after preprocessing.

---

###  3. Exploratory Data Analysis

The project investigates:

* Churn distribution
* Contract-based churn patterns
* Customer tenure
* Monthly charges
* Total charges
* Service usage
* Numerical relationships

---

###  4. Data Visualization

Multiple visualization techniques are used, including:

* Bar charts
* Histograms
* Box plots
* Scatter plots
* Correlation heatmaps
* Interactive Plotly charts

---

###  5. Interactive Analytics

The notebook includes interactive Plotly visualizations that allow users to explore customer churn patterns dynamically.

You can investigate relationships between:

```text
Contract → Churn
Contract → Monthly Charges
Tenure → Total Charges
```

---

###  6. Automated Insights

Instead of manually entering observations, important metrics are calculated directly from the dataset.

The notebook automatically identifies:

* Overall churn rate
* Contract categories with different observed churn rates
* Average monthly charges
* Average customer tenure
* Customer retention statistics

This makes the analysis reproducible and data-driven.

##  Exploratory Analysis

### Churn Distribution

The analysis examines the proportion of customers who stayed versus customers who left.

### Contract Analysis

Different contract categories are compared to understand their observed churn patterns.

### Tenure Analysis

Customer tenure is explored to identify patterns between customer longevity and churn.

### Billing Analysis

Monthly and total charges are analyzed to understand their relationship with customer churn.

### Correlation Analysis

A correlation heatmap is used to examine relationships among numerical variables.

---

##  Data Story

The analysis demonstrates that customer churn is not represented by a single variable.

Instead, several customer characteristics can be explored together, including:

```text
Contract
   +
Tenure
   +
Monthly Charges
   +
Services
   +
Customer Characteristics
   ↓
Customer Churn Patterns
```

These relationships provide a foundation for further investigation and future predictive modeling.

> **Note:** The project focuses on exploratory relationships and does not claim that an observed relationship represents a causal effect.

##  How To Run

### 1. Clone the repository

```bash
git clone https://github.com/rohanbhowm25308/customer-churn-analysis-python.git
```

### 2. Navigate to the project

```bash
cd customer-churn-analysis-python
```

### 3. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn plotly jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open

```text
Customer_Churn_Analysis_Using_Python.ipynb
```

### 6. Run all cells

Execute the notebook from top to bottom to reproduce the complete analysis.
